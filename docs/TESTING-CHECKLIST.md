# Manual Testing Checklist

- [ ] Home page loads and navigation links work.
- [ ] Quick search opens results with the entered keyword/budget.
- [ ] Search filters listings by area, university or PG name.
- [ ] Rent, preference and food filters update results.
- [ ] Sort by rent and rating changes result order.
- [ ] PG card opens the correct detail page.
- [ ] Save action appears in Saved and remains after refresh.
- [ ] Compare action adds a stay to Compare; remove action works.
- [ ] Detail page shows cost breakdown, facilities, rules and reviews.
- [ ] Owner demo login opens dashboard.
- [ ] Owner can add a listing and see it in dashboard after refresh.
- [ ] Layout is usable at desktop, tablet and mobile widths.

Note: This is a frontend-only demo. Validate all real-world property details independently.
